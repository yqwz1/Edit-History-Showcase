# Sensitive issues

Do not post secrets, full history files, proprietary project data, paid package contents, or purchase information publicly.

For a released Asset Store version, use the private support contact on the publisher profile. That address has not yet been announced for this pre-release and must be configured before launch. Do not assume GitHub private vulnerability reporting is enabled.

For sanitized ordinary bugs, use the issue form. See [data and privacy](docs/DataAndPrivacy.md) for what the recorder stores.
