# Support and feedback

Check [troubleshooting](Troubleshooting.md) and [compatibility](Compatibility.md) first. Searchable records do not imply restoration support.

Use [GitHub Issues](https://github.com/yqwz1/Edit-History-Showcase/issues) for sanitized bug reports and feature requests. Choose the matching form under **New issue**. For a released Asset Store purchase, use the publisher profile's support contact for private or purchase-specific matters.

## Bug reports

Include:

- Tool version, or identify the pre-release build.
- Full Unity Editor version and OS.
- Target kind: scene component, prefab instance, or asset.
- Inspector/component type and sanitized field path/type.
- Numbered reproduction steps, expected behavior, and actual behavior.
- Relevant sanitized Console error text or cropped screenshots.
- Whether it also happens in a fresh project with a standard Inspector.

Record the original error before resetting data. Prefer a minimal reproduction description to a full project upload.

## Private information

GitHub issues are public. Never post invoices, purchase/payment details, tokens, full history JSON, proprietary files, or the paid implementation. Redact sensitive error text. Use private publisher support for sensitive matters, including possible security/data-exposure issues, once that channel is available.

## Feature requests

Describe the workflow, current workaround, and smallest useful improvement. Requests are feedback, not a delivery commitment. No response-time or future-feature guarantee is made here.
