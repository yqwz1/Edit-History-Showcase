# Edit History documentation

Edit History records Inspector property edits in Unity Edit Mode, lets you search recorded values, and restores supported component fields individually.

**Pre-release documentation.** The intended distribution is a paid Unity Asset Store package. No public release or purchase link is announced here. The current development target is Unity **6000.3.9f1**.
